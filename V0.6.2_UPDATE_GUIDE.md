# Legacy in Stone v0.6.2 update

This release adds a required owner sign-in, cloud-first catalog loading, persistent in-dialog status messages, synchronization progress, private cloud uploads for new photos/documents, and a resumable migration control for the existing media files.

## Before uploading the files

In Supabase, open **SQL Editor**, create a new query, paste the complete contents of `supabase/v0.6.2-migration.sql`, and click **Run**.

## GitHub update

Upload/replace the v0.6.2 files in the same repository folder that contains `index.html`.

**Preserve your existing `cloud-config.js`.** The packaged file is a blank template and must not overwrite the configured version in GitHub.

Suggested commit: `Add cloud-first access and private media migration v0.6.2`

## First use

1. Wait for Netlify to publish the GitHub commit.
2. Open a new InPrivate Edge window.
3. Sign in at the new Legacy in Stone login screen.
4. Confirm that 594 records load from Supabase.
5. Open Settings & Backup. The synchronization result is now shown inside the dialog.
6. Use **Migrate Existing Media** only while the Netlify site remains private. It uploads the bundled photographs/documents to the private `collection-files` bucket and can be safely resumed if interrupted.

## Privacy status

New uploads are private in Supabase Storage. Existing media remains bundled with the Netlify deployment during this migration release. Keep Netlify access private until the migration completes and a later cleanup release removes those static copies.
